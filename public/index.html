    1. 1
      Open Google AI Studio

    2. 2
      Create an API key

      Click Create API key, then copy it.

    3. 3
      Paste it here

    Your key stays on this computer. On Gemini's free tier, Google may use what you send, including your résumé text, to improve its products.
